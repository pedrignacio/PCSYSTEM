# Página de Productos - PCSystem

## 📦 Descripción

Nueva página dedicada a mostrar el catálogo de productos de PCSystem, incluyendo componentes de PC, periféricos, accesorios gaming, merchandising anime y equipos de seguridad.

## 🚀 Características

- **Catálogo completo**: 22 productos organizados por categorías
- **Filtrado por categoría**: 8 categorías diferentes (Todos, Componentes PC, Periféricos, Gaming, Accesorios, Almacenamiento, Anime/Coleccionables, Seguridad)
- **Búsqueda en tiempo real**: Busca productos por nombre o descripción
- **Diseño responsivo**: Optimizado para móviles, tablets y desktop
- **Animaciones suaves**: Transiciones fluidas con Framer Motion
- **Integración WhatsApp**: Cada producto tiene un botón para consultar directamente

## 📁 Archivos Creados

1. **`/app/productos/page.tsx`** - Página principal de productos
2. **`/sections/Products.tsx`** - Componente de la sección de productos
3. **`/components/ProductCard.tsx`** - Componente reutilizable para tarjetas de producto

## 🔗 Navegación

El header ha sido actualizado para incluir un link a "Productos" que lleva a `/productos`

## 🛠️ Categorías de Productos

1. **Componentes PC**: Procesadores, tarjetas gráficas, RAM, placas madre
2. **Periféricos**: Monitores, teclados, mouse, webcams
3. **Gaming**: Controles, auriculares, sillas gaming
4. **Almacenamiento**: SSD, discos duros externos, pendrives
5. **Accesorios**: Cables, hubs, pasta térmica
6. **Anime/Coleccionables**: Figuras, posters, tazas
7. **Seguridad**: Cámaras IP, kits de vigilancia

## 💰 Formato de Precios

Los precios se muestran en pesos chilenos (CLP) con formato local.

## 📱 Contacto

Cada producto incluye un botón "Consultar" que abre WhatsApp con un mensaje pre-escrito mencionando el producto específico.

## 🎨 Diseño

- Fondo oscuro con elementos decorativos de gradiente
- Tarjetas con efecto hover
- Badges de stock
- Iconos representativos para cada categoría
- Diseño consistente con el resto del sitio
